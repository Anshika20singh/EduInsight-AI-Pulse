# EduInsight – AI Pulse Edition

### Student Success Analytics Dashboard

EduInsight is an interactive student performance analytics dashboard designed to visualize academic data and provide meaningful insights.

## Project Overview
The dashboard analyses student academic records through visualizations, charts, KPIs and interactive filters.

## Dataset
- 500 student records
- 14 attributes
- 5 departments
- 6 semesters

## Key Features
- Student performance KPIs
- Department-wise analysis
- Semester performance trends
- Pass/fail distribution
- Grade distribution
- Attendance vs final marks
- Student academic risk monitoring
- Interactive filters

## Technologies Used
- HTML
- CSS
- JavaScript
- HTML Canvas
- Microsoft Excel

## Project Files
- `EduInsight_AI_Pulse_Edition.html` – Main dashboard
- `EduInsight_AI_Student_Dataset.xlsx` – Student dataset

## How to Run
1. Download the repository.
2. Open `EduInsight_AI_Pulse_Edition.html` in a web browser.
3. Explore the dashboard and its interactive filters.
